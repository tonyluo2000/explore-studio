## Runtime presentation boundary

Twenty Trail-bearing session profiles opt in exact mission/package pairs, including known
reference, generator and recovery identities. Unknown packages remain plain by default.
S01–S09 policies are retained; no mission-wide wildcard enables unrelated packages.

For a student-owned package with changed identity, the explicit `--presentation-session Sxx`
option selects that session's cosmetic profile only with a supported explicit mission. The option
is documented in each new Trail guide. Unknown sessions, S26 and mismatched missions are rejected.
A launch omitting its mission still runs the original plain free-play Trail. The CLI keeps validation
and JSON output independent of renderer imports; a clean-subprocess regression protects this.

Within opted-in later profiles only, validated object kinds select private visual roles:

- Nova retains trusted course art. Keepers use the existing Guide art or authored-color fallback.
- Toggle lamps distinguish OFF/ON by light, core and sparks, preserving both authored colors.
- Every counter receives its own bounded charge-cell pose from its own authored goal/count.
  Cells saturate visually; the actual numeric counter continues after goal, unchanged.
- Ordinary objects receive three distinct engraved instrument silhouettes and a white visit tick.
- Sequence keepers receive three small prefix cells that follow actual progress and reset evidence.
- Conditional dialogue bubbles echo the line already selected by the scene, rather than substituting
  or hard-coding student messages. Branch-aware talk cues observe existing evidence.
- Shared prompt, wrapped feedback, mission-aware HUD, audio and first-completion celebration apply.

Only presentation configuration plumbing touches the scene. Gameplay update, mission completion,
package schemas, contributions, authored colors/coordinates/text and workspace protections are unchanged.
Tests exercise repeated interactions, independent counters, both Boolean branches, all OR cases,
sequence reset/completion, changed student package/object ids and CLI opt-in validation.
