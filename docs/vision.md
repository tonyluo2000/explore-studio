# Explore Studio — Vision

## What We're Building

Explore Studio is an interactive educational environment where students learn to
program by building and exploring virtual worlds. Instead of traditional
textbook exercises, students write code that directly shapes the world around them —
placing terrain, spawning entities, scripting behaviors, and solving puzzles.

## Why It Matters

Most introductory programming tools fall into one of two camps:

1. **Scratch-style block editors** — accessible but limited in teaching
   real-world programming concepts.
2. **Traditional IDEs and textbooks** — powerful but intimidating and
   disconnected from immediate, visual feedback.

Explore Studio bridges that gap. It provides the immediacy of a game
environment with the depth of a real programming language.

## Core Principles

- **Learn by building.** Every concept is taught through a concrete,
  visual outcome.
- **Immediate feedback.** Changes to code produce visible results in
  seconds.
- **Progressive complexity.** Students start with simple commands and
  gradually reach full Python programs.
- **Teacher-friendly.** Educators can design custom lessons, track
  progress, and adapt content to their classroom.
- **Open by default.** The engine, curriculum, and tooling are all
  open-source.

## What Explore Studio Is Not

- Not a replacement for professional game engines (Unity, Godot).
- Not a full programming language — Python is the language; we
  provide the environment.
- Not a passive tutorial platform — students are builders, not
  spectators.
