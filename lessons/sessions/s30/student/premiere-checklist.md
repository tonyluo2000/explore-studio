# S30 World Premiere Checklist

Use this checklist as a speaking and recovery aid, not as a mastery score.

## Before the visitor arrives

- [ ] My reviewed S29 state is committed and the working tree is understood.
- [ ] The focused learner tests and appropriate full suite are green.
- [ ] `explore-package validate` reports valid with zero issues.
- [ ] Two fresh local exports have identical SHA-256 and bytes.
- [ ] I can name every exported member and explain why the order is stable.
- [ ] No archive, temporary output, credential, or private notification is staged.

## My uninterrupted demonstration path

- [ ] State the expedition premise and visitor payoff.
- [ ] Trace source input → local Python modules → deterministic YAML.
- [ ] Explain one meaningful algorithm and why its output order is stable.
- [ ] Show one normal, boundary, invalid, and regression test.
- [ ] Explain validation and the two-export comparison.
- [ ] Launch Mission 16 `present-your-capstone-expedition`.
- [ ] Visit Echo Lens → Wind Dial → Comet Bell and explain the M14 shared style.
- [ ] Demonstrate the existing M15 ordered sequence and its reset behavior.
- [ ] State that M16 Complete means only the guided object tour is complete.
- [ ] Explain one debugging or refactoring story and all accepted AI assistance.

## Rehearsed recovery

- [ ] Likely failure selected: validation / test / export / Trail focus or launch.
- [ ] Symptom I will name before touching files: ___
- [ ] First evidence I will read: ___
- [ ] One bounded corrective action: ___
- [ ] Exact check I will rerun: ___
- [ ] Resume point in the demo: ___

If live recovery would consume the presentation, stop changing files. Show the
last clean receipt, describe the predicted correction, and continue through the
text/teacher-run accessibility path. Never conceal a red check or improvise a
schema, runtime feature, credential, publication, or deployment step.

## Close

- [ ] Teacher rubric evidence is recorded separately from Trail completion.
- [ ] Final `git status --short`, diff, staged diff, and reviewed commit complete.
- [ ] Optional tag is local only and points to the final reviewed commit.
- [ ] I did not publish or deploy the package.
