# My Explore Journey

This is my journal for the whole school year. After a class, I write a very
short entry here: 2–3 minutes, short phrases are fine. No essays.

**This file is mine.** It lives in `my-explore-world`, next to the course
folder. Course updates never change it: `make-my-world.py` only creates this
file when it is missing, and it never replaces or edits it once it exists.

Near the end of the course (S30), I will read my entries again to prepare my
final presentation. Nothing here is uploaded or shared unless I choose to.

**Place rule.** Write only a general place: `Home`, `School`, `New York`,
`Boston`, `Grandma's house`. Never write a street address, a school name, or
GPS coordinates. `Prefer not to say` is always fine.

**Weather is optional.** Look out the window and write what you see: `Sunny`,
`Rainy`, `Snowing`, `Cloudy`, `Hot`, `Cool`, `68°F`, or `Don't know`. No app
or website is needed. It is for memory and atmosphere, not accuracy.

**Two different places.** `Place` is where *you* were in real life.
`Explore-world location` is where your *Explorer* was in the world you are
building.

**How to add an entry**

1. Open `my-explore-world/journey.md` in VS Code.
2. Copy the blank entry below to the end of this file.
3. Fill in each line with a few words. Skip a line if you want.
4. Save the file.

Blank entry to copy:

```text
## S__ — <session or milestone name>
Date:

Weather:
Explore-world location:

```
