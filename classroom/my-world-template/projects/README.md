# My Projects

This folder holds Explorer Packages and other world projects that belong to
you. Session 2 starts with `moon-compass/`. Edit, validate, and launch that
student-owned copy; do not edit the seed copy inside the Course Kit.

Anything you put here belongs to you. Running `make-my-world.py` again adds
only missing seed files and never changes an existing project file. Replacing
the Course Kit does not touch this folder.
